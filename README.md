# Portfolio Pessoal - Versão 2

Este é o meu **portfolio pessoal versão 2**, desenvolvido com as tecnologias **Next.js**, **JavaScript**, **Tailwind CSS**, **Framer Motion** e **EmailJS**. O objetivo deste projeto é demonstrar minhas habilidades e experiências como desenvolvedor web, criando uma aplicação fluida, acessível, otimizada para SEO e com um design atrativo, refletindo as melhores práticas de desenvolvimento.

## Tecnologias Utilizadas

- **Next.js**: Utilizado para otimizar as rotas, garantindo um carregamento rápido das páginas com renderização estática e server-side, além de facilitar o SEO.
- **JavaScript**: Utilizado como linguagem principal para a construção da aplicação.
- **Tailwind CSS**: Escolhido pela sua flexibilidade e agilidade na estilização, criando um layout limpo e moderno.
- **Framer Motion**: Implementado para criar animações dinâmicas, transições suaves e interatividade na aplicação.
- **EmailJS**: Integrado para permitir o envio de mensagens diretamente pelo site, sem necessidade de backend.

## Funcionalidades

As seções do meu portfolio incluem:

- **Página Inicial**: Apresenta uma introdução interativa com animações suaves.
- **Página de Projetos**: Exibe meus trabalhos com transições dinâmicas.
- **Subpágina de Projetos**: Detalha cada trabalho com informações técnicas.
- **Página de Skills**: Lista minhas habilidades de forma interativa.
- **Página Sobre Mim**: Onde compartilho minha trajetória profissional.
- **Página de Email**: Para contato direto com os visitantes.
